# ClassPulse
### Multimodal Attendance & Engagement Agent

An AI-powered, privacy-preserving classroom
intelligence system designed to automate
attendance tracking and analyze classroom
engagement.

## Features
- Automated attendance management
- Camera-based face detection
- Classroom engagement analysis
- AI-driven teaching suggestions
- Student session analytics
- Offline-first architecture

## Technologies Used
- Python
- Flask
- OpenCV
- NumPy
- HTML, CSS, JavaScript
- SQLite

## Installation

1. Clone the repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open http://127.0.0.1:5000

## Privacy
Designed for local execution without
requiring cloud AI services.
